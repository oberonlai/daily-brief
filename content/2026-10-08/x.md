# X 熱門早報｜2026-10-08（四）

今天最大的消息是 OpenAI 對所有人推出 GPT-6 和會直接生成互動介面的「Intelligent UI」，Anthropic 同日發表更便宜的 Claude Haiku 5.5；WordPress 圈有 WPVibe 一個月從兩萬衝到六萬安裝，SEO 圈則在討論這個產業的處境越來越艱難。

### 1. OpenAI（@OpenAI）｜AI
OpenAI 宣布 GPT-6 和 Intelligent UI 開始對 ChatGPT 所有使用者推出，回答裡會直接出現圖表、按鈕、表單這類互動元件，讓複雜問題更容易看懂。這則有近一萬四千讚、三千八百多次收藏，是今天互動最高的一則。
https://x.com/OpenAI/status/2107894997538525580

### 2. Anthropic（@AnthropicAI）｜AI
Anthropic 發表最新的小模型 Claude Haiku 5.5，貼文有近四千九百讚。Claude Code 負責人 Boris Cherny 補充說，它在 10 萬 token 的上下文下比 Haiku 4.5 便宜 10 倍，對大量跑 agent 子任務的人很划算。
https://x.com/AnthropicAI/status/2107894208547983705

### 3. Google DeepMind（@GoogleDeepMind）｜AI／科技
SynthID Detector 開放給所有人使用，可以上傳圖片、影片或音訊，檢查是不是由 Google 或合作夥伴（包括 OpenAI、NVIDIA、Kakao，之後還有 Apple）的工具生成。做內容審核或要辨識 AI 素材的團隊可以直接拿來用。
https://x.com/GoogleDeepMind/status/2107834249680499136

### 4. Peter Steinberger（@steipete）｜MCP／Agent
他分享在 OpenAI DevDay 2026 的演講，主題不是單一 agent 有多強，而是團隊怎麼用 agent 一起協作。這則有四百多次收藏，想把 agent 帶進團隊流程的人值得一看。
https://x.com/steipete/status/2107911769767440832

### 5. DAIR.AI（@dair_ai）｜開發工具
一篇論文用同一個模型比較 Claude Code、mini-SWE-agent 和 OpenCode，發現換 harness 對 SWE-bench 分數的影響跟重跑一次差不多。真正差在成本：系統提示詞和工具定義每一步都會重送，保持精簡最多能省 3 倍費用而不掉準確率。
https://x.com/dair_ai/status/2107920656788767098

### 6. Siddhant Mohan（@siddhantmohan1）｜開源
他推出開源的 AI 程式碼審查工具，結合 100 多個掃描器和一個 AI 審查者，每個發現都要被回應，直接用你自己的 Claude Code 或 Codex 登入在 push 前跑。收藏數八百多，主打取代每人每月 60 美元的付費審查服務。
https://x.com/siddhantmohan1/status/2107645119130440006

### 7. Syed Balkhi（@syedbalkhi）｜WordPress／MCP
WPVibe 安裝數突破六萬，一個月前才兩萬。它讓 WordPress 網站可以接上 ChatGPT、Claude、Cursor 等 AI 工具來建站和管理，是目前 WordPress 接 AI 工具成長最快的案例之一，跟我們在做的 WP MCP 方向很接近。
https://x.com/syedbalkhi/status/2107770395285664053

### 8. Matt Mullenweg（@photomatt）｜WordPress
接著 WordPress 7.1.3 的安全更新，他說今年會是「安全之年」，新功能可能沒那麼多，但不把安全當優先的人遲早會出事。手上有客戶網站的話，維護排程要跟上。
https://x.com/photomatt/status/2107611691924259173

### 9. Kevin Indig（@Kevin_Indig）｜SEO
他直說不管是 SEO 這個流量管道還是整個 SEO 產業，處境都「不太好」：更多人改用 AI 找答案、Google 更廣泛推出 AI Overviews，又給廣告更多版面，流量還能拿，但空間小很多。這則引來二十多則回覆討論。
https://x.com/Kevin_Indig/status/2107864443866484762

### 10. Lily Ray（@lilyraynyc）｜SEO／SaaS
她又找到一家在一月核心更新被重挫的 B2B SaaS，部落格塞滿清單文（其中 38 篇在推自家產品）、終極指南和替代方案頁。她另外指出，Google 排名掉了之後，ChatGPT 的引用次數也跟著下滑。
https://x.com/lilyraynyc/status/2107850914799243294
