# X 熱門早報｜2026-10-07（三）

今天 AI 圈最熱的是 OpenAI 公布內部前沿模型產出的一批數學新成果，以及 Anthropic 擴大資安專業人員的模型存取計畫；WordPress 7.1.3 釋出 7 個安全修正要盡快更新，SEO 圈則在討論 Google 開始寄信告訴站長有多少人把網站設為「偏好來源」。

### 1. OpenAI（@OpenAI）｜AI
OpenAI 宣布釋出一批由內部前沿模型產出的數學新成果，並說明過程中有諮詢普林斯頓高等研究院的數學與 AI 顧問小組。這則有四千五百多讚、一千多次收藏，是今天互動最高的 AI 官方消息。
https://x.com/OpenAI/status/2107596713791767021

### 2. Anthropic（@AnthropicAI）｜AI／資安
Anthropic 擴大「Cyber Verification Program」，通過驗證的資安專業人員可以使用 Claude Mythos 5.1、Opus 5.5 和 Sonnet 5.5，並搭配專為防禦性工作設計的安全機制。做資安或滲透測試的團隊可以留意申請資格。
https://x.com/AnthropicAI/status/2107546569654636883

### 3. Boris Cherny（@bcherny）｜開發工具
Claude Code 的負責人說，他平常就是像跟同事講話一樣跟 Claude 下指令，沒有什麼提示詞祕訣，多數任務不需要過度鋪陳或寫得很死，給目標讓它自己想辦法就好。收藏數超過三千，很多人在討論這種「少即是多」的用法。
https://x.com/bcherny/status/2107565388250874193

### 4. Thariq（@trq212）｜MCP／Agent
Anthropic 的 Thariq 說，Claude 接下來會越來越走向「大腦在雲端、雙手在本機」的架構：推理在雲端跑，再透過本機的能力操作你的電腦，他也在 Latent Space 節目裡談到這個方向。對在設計 agent 跟本機工具串接的人是重要訊號。
https://x.com/trq212/status/2107580785456976085

### 5. Google DeepMind（@GoogleDeepMind）｜開源
Google DeepMind 推出 EmbeddingGemma 2，是他們第一個原生多模態、可在裝置上跑的開放嵌入模型，把程式碼、圖片、音訊和影片放進同一個向量空間。做本機 RAG 或多媒體搜尋的開發者可以直接拿來試。
https://x.com/GoogleDeepMind/status/2107502286758895878

### 6. WordPress（@WordPress）｜WordPress
WordPress 7.1.3 釋出，包含 7 個安全修正和 4 個錯誤修正，官方呼籲立刻從後台更新。手上有客戶網站的話，今天最好排進維護清單。
https://x.com/WordPress/status/2107519282183655446

### 7. Weston Ruter（@westonruter）｜WordPress／開發工具

https://x.com/westonruter/status/2107480172597588067

Google Search Console 開始寄信告訴站長，有多少使用者把你的網站加為「偏好來源」，他一口氣收到好幾封。他另外提到 Google 的問卷顯示，正考慮把這項數據直接放進 Search Console 報表。
https://x.com/glenngabe/status/2107498770686755302

### 9. Lily Ray（@lilyraynyc）｜SEO／AI
她觀察到 ChatGPT 越來越常用 site: 搜尋，代表網站的子網域也更常被拿來生成回答。她建議先盤點所有子網域，想清楚哪些內容（例如測試站）你其實不想讓 LLM 看到。
https://x.com/lilyraynyc/status/2107471088020046215
