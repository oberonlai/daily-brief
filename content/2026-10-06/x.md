# X 熱門早報｜2026-10-06（二）

今天最熱的是 AI 產業動向：OpenAI 宣布把內容來源標記擴大到文字，另有報導指微軟和 Meta 正在大砍內部 Claude 用量。開源圈 Hugging Face 把 Claude Code、Codex 等 coding harness 變成強化學習環境；WordPress 這邊，官方標準的 MCP Adapter 正式釋出，SEO 圈則持續追 Google 的「Effort」定義和垃圾內容更新。

### 1. OpenAI（@OpenAI）｜AI
為了因應歐盟法規，OpenAI 要把內容來源標記從圖片、音訊擴大到文字，同時也坦言目前的文字浮水印技術限制很大。這則有將近五千讚、五百多則回覆，是今天 AI 圈互動最高的官方消息。
https://x.com/OpenAI/status/2107164650249101695

### 2. NIK（@ns123abc）｜AI／SaaS
轉述 The Information 報導：微軟和 Meta 正積極減少員工使用 Claude，微軟內部 Claude 支出砍了三分之一以上，每人每月 token 預算從 10 萬美元降到 1 萬美元，Copilot 也改成自動導向較便宜的模型。這是二手轉述，細節以原報導為準。
https://x.com/ns123abc/status/2107192632573096320

### 3. Clem Delangue（@ClementDelangue）｜開源／Agent
Hugging Face 執行長宣布，他們把 Claude Code、Codex、Hermes、Pi、opencode 等 coding harness 原封不動變成強化學習環境，任何開源模型、任何任務集都能用，全部開源。他舉例同一個模型、同一組權重，換不同 harness 成績就從 62% 掉到 33%，說明 harness 的影響有多大。
https://x.com/ClementDelangue/status/2107120717980471638

### 4. Thariq（@trq212）｜開發工具
他正在做一個讓 Claude Code 產出更好 HTML 計畫書的 skill：用白話說明、附程式碼片段、主動列出待確認問題，還會畫介面草圖，並用 linting 減少 Claude 常見的失誤。目前開放大家試用回饋，收藏數超過一千五。
https://x.com/trq212/status/2107192901537329354

### 5. DAIR.AI（@dair_ai）｜MCP／Agent
推薦一篇微軟與合作者的論文 CorpusMap：讓 agent 在大型文件庫裡搜尋前，先把反覆出現的實體整理好，每個實體各給一頁資料。做 RAG 或文件搜尋 agent 的人值得收藏。
https://x.com/dair_ai/status/2107146326639358188

### 6. Genex（@genex_games）｜開源
Genex 是一套用 AI 做遊戲的桌面 App，MIT 授權開源，可以接本機模型或直接用 Claude Code／ChatGPT 訂閱，搭配會自我改進的 harness、Three.js 和 Blender 等工具，之後還會出 Unity 和 Unreal 外掛。
https://x.com/genex_games/status/2107148754633507237

### 7. Cyrus Shepard（@CyrusShepard）｜SEO
Google 更新「有幫助的內容」文件後，大家都在討論「Effort」，但他提醒 Google 說的 Effort 不等於花多少工夫。在大量低成本 AI 內容的時代，重點是內容有沒有真正的獨特價值。
https://x.com/CyrusShepard/status/2107191555828404625

### 8. Barry Schwartz（@rustybrick）｜SEO
整理 Google 在 Search Central Live 談垃圾內容更新的重點：為什麼最近更新這麼頻繁，以及接下來可能的改變。搭配 Glenn Gabe 的引述，Google 認為大量產製的內容正在變成比連結垃圾更大的問題，預期還會有更多垃圾內容更新。
https://x.com/rustybrick/status/2107074663390019748

### 9. Aleyda Solis（@aleyda）｜SEO
分享 Nacho Mascort 整理的 Google 品質觀：品質是什麼、怎麼衡量，以及被核心更新打到之後要多久才能恢復，內容來自巴塞隆納的 Search Central Live Deep Dive。跟最近「大更新將至」的討論一起看很有參考價值。

### 10. Jason Adams（@jasontheadams）｜WordPress／MCP
WordPress MCP Adapter 正式釋出，這是 WordPress 官方標準的 MCP 外掛，架構上特別顧到不同 MCP 版本的向下相容。他建議想在網站或外掛裡加 MCP 的人都直接用這套，WP MCP 相關開發可以以它為基礎。
