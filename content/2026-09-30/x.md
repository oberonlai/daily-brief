# X 熱門早報｜2026-09-30（三）

OpenAI 常駐 agent「Dots」登場卻卡在現場 demo 與定價（對上 Meta Muse 免費）；Greg Brockman 同步丟出 frontier RL 訓練資安指南。SEO 圈持續吐槽 AI Overviews 被刷屏、LLM 引用被 GEO 廠商壟斷；Web 側則出現 W3C WebSkills 草案，補齊 WebMCP／裝置端 LLM。

### 1. Greg Brockman（@gdb）｜AI coding agents
OpenAI 總裁整理目前對「frontier RL 訓練」的資安實務：長時程、高算力的強化學習管線，哪裡該隔離、哪裡該稽核。做 agent／模型訓練基建的人，這份比口號級安全聲明更值得讀。
https://x.com/gdb/status/2104821232441160070

### 2. François Chollet（@fchollet）｜AI coding agents
Chollet 重提 agi 評測觀點：真正測「人類級通用性」的方式，是模型能否在 ARC-AGI-(n+1) 一釋出就立刻過關。對評測與 agent 能力上限討論，這則是很乾淨的一句定義。
https://x.com/fchollet/status/2104993851903815978

### 3. KanekoaTheGreat（@KanekoaTheGreat）｜AI agents／SaaS
OpenAI 新常駐 agent Dot（外觀很像 Grok Bot 路線）在首場 live demo 卡住沒回應；主持人也吐槽為什麼自己的 agent 還要響三聲才接。產品敘事很滿，現場穩定度仍是門檻。
https://x.com/KanekoaTheGreat/status/2105001388627706301

### 4. OK Then（@okaythenfuture）｜AI agents／SaaS
對照 Meta Muse 免費給中小企業用、OpenAI 卻把 always-on agent 綁在約 $200／月方案：作者認為這暴露 OpenAI 在 consumer agent 算力擴張上的瓶頸，而不只是產品定位差異。
https://x.com/okaythenfuture/status/2104995389460148530

### 5. Sébastien Lorber（@sebastienlorber）｜WebMCP／開放網頁
W3C 研討會出現 WebSkills 提案（華為貢獻者）：Agent Skills 存瀏覽器、Web Worker 跑腳本、`navigator.webskill` API，並與 WebMCP／裝置端 LLM 互補。站點若要給 agent 做事，規格層又多一塊拼圖。
https://x.com/sebastienlorber/status/2104878779348734451

### 6. Glenn Gabe（@glenngabe）｜SaaS／WebMCP
Shopify 宣布瀏覽器端 AI agent 可經 WebMCP 在商家站完成結帳（先前已支援店面與購物車探索）。電商若要給 agent「買得到」，checkout 這關開始有正式產品路徑。
https://x.com/glenngabe/status/2104903711176663160

### 7. Lily Ray（@lilyraynyc）｜SEO × AI
她認為用 Google AI Overviews／AI Mode 做深度研究越來越難：很多主題已被洗到無法直接信任，使用者必須自己會過濾。對依賴 AI 摘要當研究起點的人，這是現場警報。
https://x.com/lilyraynyc/status/2104906792631443474

### 9. Mark（@MRRydon）｜WebMCP／開放網頁
整理 OpenAI WebMCP Challenge 得獎概念：網站改為公布 agent 可呼叫的結構化工具，而不是逼 agent 像人類一樣亂點 UI。對 WordPress／電商要接 agent 流量，這條路比「再做一個聊天框」更對題。
