1. 多裝置 AI 測試員：行動 App 驗收即服務

  • GitHub：https://github.com/pierridotite/mobile-agent-testers（建立：2026-11-16）
  • 來源重點：用 Claude Code agent 在 20 種手機人設、iOS Simulator／Android emulator 上並行測試，跑在 GitHub 免費 runner，剛上 Product Hunt，約 1,450 星。
  • 為什麼值得做：小團隊做 App 沒有 QA 預算，上架前常被各種機型、語系問題打槍。
  • 產品構想：託管版「上架前 AI 驗收」：上傳 APK／TestFlight，選人設（長輩、低階機、英文介面），產出可重現的 bug 影片與報告。
  • 難度與切入點：中高。先做 Android 單一流程（註冊→付款）的測試，按次計費。

2. 瀏覽器內 Linux 沙盒：教學與程式碼執行 SaaS

  • GitHub：https://github.com/pithings/unkernel（建立：2026-11-12）
  • 來源重點：真正的 Linux kernel 編成 WebAssembly，不到 1 秒開機進 shell，可跑 Alpine／Debian 套件，完全在使用者裝置運行、不用伺服器。
  • 為什麼值得做：線上課程、技術文件、面試平台都需要隔離環境，傳統雲端沙盒按量計費成本高。
  • 產品構想：可嵌入的「點一下就能操作」終端 widget，供技術教學站、文件與 API demo 使用；伺服器成本趨近於零。
  • 難度與切入點：中。先做嵌入 SDK＋預載環境模板（Node、Python、Git），訂閱制賣給課程平台。

3. AI Agent 設定與程式碼安全掃描：PR 檢查服務

  • GitHub：https://github.com/erkamyaman/safe-anything（建立：2026-11-22）
  • 來源重點：Rust 單一指令掃 XSS、SQL injection、外洩金鑰、相依套件 CVE，連 AI agent 設定檔也檢查，每個發現附行號、原因、修法。

  • 難度與切入點：低中。包裝既有掃描器，差異化在繁體中文報告與台灣合規（個資法）提示。
